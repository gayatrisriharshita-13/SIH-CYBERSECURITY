# SIH Cybersecurity Project Contract

## Project

Privacy-first, multi-signal email threat detection and analyst triage system.

## Final Workflow

User
→ Chrome Extension
→ Local Privacy/Minimization
→ FastAPI Backend
→ AI/ML + Threat Intelligence
→ Explainable Risk Score
→ MongoDB
→ Analyst Dashboard
→ Analyst Decision
→ Evidence Integrity

## Rules

1. Do not change the overall architecture without team-lead approval.
2. Do not change API field names without updating API_SCHEMA.md.
3. Do not hard-code API keys.
4. Do not upload unnecessary personal email data.
5. Do not create duplicate databases or duplicate backend services.
6. Every module must have documented inputs and outputs.
7. Every completed module must include a working test/demo.
8. No technology is added unless it has a clear purpose in the project.
